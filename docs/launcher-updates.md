# Совместимые обновления Nevermore

## Установка

Изменены серверные файлы:

- `apps/api/src/launcher/releases.js` — создание и проверка двух ZIP, отдельные размеры и SHA-256, защита опубликованных файлов, добавление совместимого пакета к существующей публикации.
- `apps/api/src/server.js` — публичная раздача вариантов, выбор по User-Agent, заголовки кэша и миграция текущей публикации при старте.

Дополнительно изменены `apps/api/README.md`, `tests/launcher-release.test.js`,
`tests/zip-fixture.js`, `tests/integration.test.js` и этот документ.
Зависимости не изменялись. Пересборка фронтенда и миграция схемы БД не требуются.

После загрузки кода в установленный репозиторий:

```sh
cd /opt/mc-launcher/web_mc_launcher
sudo systemctl restart mc-launcher-server.service
sudo systemctl status mc-launcher-server.service --no-pager
sudo journalctl -u mc-launcher-server.service -n 50 --no-pager
```

Если служба на основном сервере называется иначе, используйте её действующее имя.
Публиковать 0.1.26 повторно не нужно: при старте backend проверит существующий
современный ZIP и его метаданные, добавит `0.1.26-legacy.zip` и атомарно сохранит
его метаданные в существующий каталог PostgreSQL. Исходный ZIP не перезаписывается.
Последующие публикации через ту же админку автоматически создают оба варианта.
Миграцию имени EXE на машине игрока выполняет клиент.

Проверка рабочего домена после установки:

```sh
curl --fail-with-body -i -A 'EquestrianDreamLauncher/0.1.3' \
  'https://launcher.nevermoreland.ru/api/launcher-update?platform=windows-x64'
curl --fail-with-body -i -A 'Nevermore/0.1.26' \
  'https://launcher.nevermoreland.ru/api/launcher-update?platform=windows-x64'
```

Ожидаются HTTP 200 без Location, `Cache-Control: no-store`, `Vary: User-Agent`.
Для старого клиента `url` заканчивается на `0.1.26-legacy.zip`, для нового —
`0.1.26.zip`. Оба URL относительные и остаются на HTTPS origin запроса.
В ZIP находятся ровно два корневых файла: соответствующее имя EXE и `README.txt`.

## Выполненные проверки

- `node --test tests/launcher-release.test.js`: 2 теста прошли. Проверены отсутствие авторизации и редиректов, выбор пакета для старых версий 0.1.3 и 0.1.25, нового и неизвестного User-Agent, точный JSON-контракт, заголовки, состав ZIP, двоичные данные, размер и SHA-256 скачанного файла.
- Проверены две последовательные публикации, запрет замены версии, отказ при лишних файлах и сохранение предыдущей публикации при ошибке установки второго архива. Неопубликованный файл недоступен через endpoint скачивания.
- Проверена миграция существующей публикации, повторное использование корректного файла после незавершённого коммита и отказ при повреждении без перезаписи опубликованных файлов.
- Отдельная проверка Chromium через настоящую браузерную админку использовала ZIP 0.1.26, скачанный с рабочего домена. В изолированной тестовой базе выполнены две последовательные публикации: 0.1.26 и тестовая 0.1.27, обе с одним исходным пакетом 0.1.26. После каждой проверены оба ZIP и неизвестный User-Agent; настройки игры остались прежними. Рабочий сервер при этом не изменялся.
- Исходный ZIP 0.1.26: 14 204 764 байта, SHA-256 `e3ca54ab64d03e792e77982eee7091a336b7dea5c408e0f0a05a34514e80d024`. Совместимый ZIP в проверке: 14 121 939 байт. SHA-256 EXE в обоих вариантах: `636e091a79405ac14e860207c73b0b5bbb20809a75f62d12ab2d72b801108377`. SHA-256 совместимого ZIP вычисляется при формировании; ZIP включает время записи, поэтому между отдельными формированиями его хеш может различаться.
- Подробный локальный отчёт: `artifacts/launcher-dual/real-package-check.json` (каталог artifacts исключён из Git).
- `git diff --check` и проверка синтаксиса обоих серверных файлов прошли.

Общий `npm test` с установленным Chromium: 81 тест, 74 прошли, 6 завершились
ошибкой и 1 отменён. Проблемы общего прогона: тайм-ауты существующих UI-сценариев,
React hydration error в player-site и старый тест Telegram-регистрации,
использующий `/register`. Ошибка Telegram (`callback_data.startsWith`)
воспроизведена отдельно на исходных серверных файлах из HEAD до изменений.
Специализированные тесты Telegram-входа, БД, конфигураций и обновлений прошли.
Полный локальный лог: `/tmp/nevermore-dual-full-tests.log`.

Для общего прогона в текущей среде использовались Node.js 24 и уже установленный
браузер:

```sh
PATH=/opt/mc-launcher/runtime/node/bin:$PATH \
PLAYWRIGHT_BROWSERS_PATH=/tmp/mc-launcher-playwright \
```
